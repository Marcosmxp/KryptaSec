# Architecture Decision Records

ADRs capture decisions that are expensive or confusing to rediscover later.

## Format

Create files as:

```text
NNNN-short-title.md
```

Each ADR should contain:

- Status
- Context
- Decision
- Consequences
- Alternatives considered
- Date

Statuses:

- Proposed
- Accepted
- Superseded
- Rejected

Do not delete old ADRs. Supersede them with a new ADR so the reasoning history remains visible.
